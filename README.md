# Reproducible Local Dataset Package

## Project Overview
This project implements a reproducible, research-grade data repository built around a
sensitive local dataset provided by the instructor. The objective is to ensure that cleaned
datasets, analysis outputs, and reports can be fully reproduced from the original raw data
using a version-controlled and automated workflow.

The repository is intended for internal use only and operates entirely offline.

---

## Repository Structure

data/  
├── raw/        – Original dataset provided by the instructor (unchanged)  
├── processed/  – Cleaned and transformed datasets generated by the pipeline  

src/            – Data cleaning and reporting scripts  
workflows/      – Automated workflow (Makefile)  
reports/        – Generated report artifacts  
docs/           – Metadata, data dictionary, integrity and CLI notes  

README.md  
CHANGELOG.md  
requirements.txt  

---

## Reproducibility Instructions

### 1. Recreate the Python environment
From the project root, create and activate a virtual environment:

python -m venv .venv  
source .venv/bin/activate  
pip install -r requirements.txt  

### 2. Run the full pipeline
Execute the complete automated workflow using a single command:

make -f workflows/Makefile all  

This command will:
- clean and standardize the raw datasets,
- generate processed datasets in CSV and Parquet formats,
- produce a summary report in the reports/ directory.

---

## Expected Outputs
After running the pipeline, the following files will be generated:

- data/processed/cleaned_records.csv  
- data/processed/cleaned_records.parquet  
- reports/summary.md  

---

## Data Notes and Limitations
- The raw dataset contains missing values, inconsistent date formats, and inconsistent
  capitalization in categorical fields.
- Duplicate records and invalid numeric values are removed during cleaning.
- Raw data files are treated as immutable and are never modified.
- The dataset is sensitive and intended for internal use only.

---

## Data Integrity
The integrity of the raw datasets is ensured using SHA-256 checksums.
Instructions for verifying file integrity are provided in docs/integrity_notes.md.

---

## How to Reuse Internally
This repository may be reused internally by cloning the project, recreating the environment,
and running the automated pipeline. Any modifications should be performed in separate
Git branches and documented via commits and changelog updates.
